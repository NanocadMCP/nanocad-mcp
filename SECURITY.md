# Security

## Report a vulnerability privately

Do not post exploit instructions, credentials, confidential drawings or private configuration in a public issue.

If the GitHub repository offers **Security → Report a vulnerability**, use that private channel. Otherwise use a private contact published by the maintainer. If neither is available, open an issue requesting a private security contact without disclosing vulnerability details.

Include affected component versions, impact, minimal reproduction steps and safe diagnostic evidence. Review attachments for sensitive information. There is no guaranteed response or remediation time.

See [data and privacy](docs/en/privacy.md) for normal drawing-data handling.
