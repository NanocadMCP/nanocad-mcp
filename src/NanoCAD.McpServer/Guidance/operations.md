# get_operation_result

Read an existing write's historical ledger outcome using its original bridge_instance_id and operation_id. No write payload, current document/revision or native UI access is required. wait_ms is a reader-local wait (default2000, maximum6000); cancellation does not cancel the write. The ledger belongs to the bridge lifetime and is not restored after restart.

Read found, phase, job_finished, commit_recorded, outcome, recorded_result_included and result_fingerprint together. Pending is not success. job_finished means a final queue response exists, not that the requested geometry is correct or current. found=false means unknown and never authorizes repeating a write. A historical commit remains historical after user Undo; refresh the current intended CAD context before dependent edits.

mode=result returns the original response when it fits and initial reference/warning pages. A transport receipt can omit recorded_result while preserving the known outcome and result locator. mode=references or warnings returns only that paged observation set; follow next_cursor until complete using the same bridge/operation/mode. Cursors bind to the recorded result fingerprint; if the result changes while native work finishes, restart the page. page_size controls requested response length, not total CAD content.

Reference items contain an exact ref observed in the recorded output, role and JSON-pointer provenance. They are not an inferred set of changed objects, newly read CAD identities or ownership proofs. Warning pages can fragment a long warning; reassemble by warning_index and UTF-16 text_offset through total_characters. A fragment's complete describes that warning, while the page complete describes the warning sequence. Original payload replay remains supported by its original write tool; never alter expected_revision or repeat known committed work.

# query_objects

Spline Hatch sources currently require one genuinely closed WCS XY/Z0 Spline per loop; use set_hatch_association with a fresh Hatch token to rebind the same Hatch.
